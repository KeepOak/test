# Event-bound typed macro procedures

Developer → Typed tool macros → Event procedures joins existing event primitives to imported macros. Saving creates an immutable, disabled definition. Enable explicitly, inspect a real event's resolved input, and approve its exact proposal within ten minutes. No event starts tools or a model automatically. Individual graph tool approvals still apply. Open each actual run to use the existing exact-checkpoint resume, interrupted retry/skip, and cancellation controls. Effects already performed cannot be rolled back.

Definitions use `{name, macroId, event, input}`. Input fields are scalar literals, lists of text, or `{"$event":"field"}` references to a top-level event field; no scripts, expressions, templating or new executor. Input must match the immutable imported macro's shape. A resolved proposal is capped at 16 KB. There are at most 20 procedures, ten pending events each, fifty remembered delivery slots, and twenty retained run references per procedure. Events coalesce during a one-minute gap. Only one unfinished run per procedure may be approved. Existing flow history stays in the graph runner when references age out.

| Event | Exact binding | Existing primitive and payload |
| --- | --- | --- |
| cron | `{kind:"cron",cron:"0 9 * * *",timezone:"America/New_York"}` | Scheduler tick plus the existing numeric five-field recurrence parser; `dueAt`. Missed occurrences coalesce once; next occurrence persists. |
| webhook | `{kind:"webhook",triggerId:"existing UUID"}` | Existing `/api/triggers/:id/fire` signature, timestamp/nonce, request/body and rate guards; top-level JSON payload fields. Requires replay protection and an unbound trigger. Enabling deliberately takes over that trigger's prompt path. |
| mqtt | `{kind:"mqtt",channel:"configured id",chatId:"existing short chat id",senderId:"existing short sender id",topic:"exact/topic"}` | Existing MQTT packet adapter and channel router after activation, platform, sender/pair authorization and sender ceiling; `text`, `topic`, `senderId`, `chatId`. Exact topic comes from the packet header, not publisher JSON. Matching authorized messages become proposals instead of chat turns. Retained messages and QoS2 are already suppressed; DUP-marked packets do not propose another run. |
| device | `{kind:"device",vendorId:"1234",productId:"abcd",serial:"exact serial or empty"}` | Existing opted-in USB scanner, fresh plug detection and first-scan suppression; `name`, `serial`. Exact serial matching, including empty serial; this does not enable USB or alter existing USB rules. |

The owner profile, app lock, lockdown, macro existence and current source availability are checked again at approval. Configurations cannot be edited in place; disabling discards old proposals. Original `schedule`, `trigger` or `channel` source is persisted with the graph run and remains on resume; approving an event does not promote its source to owner. Ingress has no control route to approve or resume. Run IDs represent actual graph runs only. Authenticated webhook responses distinguish owner-approval, held and coalesced/rate-held states and disclose no inputs or hold details to the sender.

## Explicit limits

Windows has no existing supported USB scanner and device bindings are held there. Trunk/session-bound webhooks and MQTT chats are held because the current macro event adapter cannot preserve a Trunk's scoped execution identity. No new MQTT subscription, broker connection, device scan, permission, autonomous Hands mode, provider request, or installer is introduced. MQTT uses the adapter's existing generated message IDs; this is not exactly-once broker processing or a durable event outbox. Webhook nonce replay storage remains process-local as in the existing trigger primitive. Errors in the USB subscriber cannot suppress original USB rules. Pending events expire rather than retry; interrupted tool effects require the original explicit resume decision. The authoring UI is English JSON, not a visual SOP editor or complete ZeroClaw approval-group/membership implementation.
