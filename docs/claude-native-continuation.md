# Native Claude continuation

Branch keeps Claude Code as an inert, authenticated transport. A provider instance binds its owner, account home, command and model; its cache additionally binds the current model-call owner, conversation, system instructions, inventory, reasoning/output schema, allowance and Trunk policy. Continuation requires an exact digest prefix of the previous canonical request and captured assistant reply. Compaction, history edits, setting changes or concurrent calls use a fresh transport. At most eight sessions are retained per provider, with a two-minute idle timeout, ten-minute lifetime and 64 completed turns.

The stream input stays open between terminal per-turn results. Each Branch turn arms the loopback relay once with a random turn marker. Only a native request bearing that marker can reach the fixed first-party Messages endpoint. Idle requests and a second native tool-loop generation are refused. Markers are local transport triggers and are replaced before forwarding; they never become model instructions.

Native MCP remains inventory-only and returns inert denials. Its internal transcript is therefore unsuitable as model history after a tool call. For every admitted generation, the relay replaces native messages with Branch's canonical structured messages, including the actual Branch tool results, and replaces tools and generation settings with the current request. It preserves the native authentication path and system environment. Captured upstream SSE remains the authoritative completion; a native error after an inert tool attempt is accepted only with the captured tool batch. Branch continues to execute tools through its approval/runtime path.

The relay is disarmed before a transport enters the idle cache. Failure, timeout or cancellation drops the transport and its owned process tree. App shutdown closes retained transports through the existing spare-agent lifecycle. No native transcript is persisted; private request files are removed when the transport closes. Historical zero-turn replay remains required when a fresh transport starts.

This is a source contract, pending installed CLI compatibility and real multi-turn acceptance. No runtime, sign-in, provider request or tests were run for this draft. A Claude Code version that exits after a terminal result will safely fall back to a fresh transport; protocol mismatches fail the call and discard the session. This path does not authorize native tool execution or additional upstream generations.
