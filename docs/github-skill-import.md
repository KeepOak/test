# Importing a public GitHub skill

Customize → Tools → Add a skill → GitHub asks for a repository owner, repository and skill folder. An empty folder means the repository root. An optional forty-character tree SHA chooses an exact revision; otherwise Branch resolves the default branch once and pins the returned tree before reading any skill bytes.

Branch accepts the exact folder's `SKILL.md` and up to twelve flat UTF-8 text references. Scripts, assets and unrelated files are left out. Symlinks, submodules, unsafe or duplicate names, incomplete trees, invalid text and files that fail their declared Git blob hash are refused. Files are fetched by immutable blob SHA, not a moving branch. The normal Agent Skills reader and Branch package preview run afterward, and every kept text file is scanned. The preview shows instructions, findings, omitted paths and the pinned revision. No repository name bypasses the scan.

Inspecting installs nothing. Branch holds at most eight previews in memory, each usable once for fifteen minutes; closing or restarting the engine loses them. Approve and install uses those exact server-held bytes, rechecks the current scan policy, and installs through the existing package workflow, switched off. Activation remains a separate owner action. Source repository, folder, tree SHA, content digest and installed skill version are saved under `skill-github:<skillId>` for later update provenance; no automatic update is started.

Both routes are owner-only, require an unlocked app and refuse short-lived keys: `POST /api/skill-installs/github` accepts `{owner, repo, path, treeSha?}`; `POST /api/skill-installs/github/install` accepts `{ticket, approve:true}`. Existing install mode must permit them. Every request uses Branch's network policy, refuses redirects and rechecks the principal immediately before sending after policy lookup. No GitHub credentials, CLI or shell are used. Each request has a twenty-second deadline, the whole read has ninety seconds, tree JSON is capped at two MiB, each file at 128 KiB, and total kept text at 512 KiB. Rate limits fail visibly without automatic retries.

The tree-first and validate-before-quarantine implementation is adapted from [Hermes Agent's GitHub source](https://github.com/NousResearch/hermes-agent/blob/a9a54245b2311c705d29050b7f9868c015917aec/tools/skills_hub_github.py) and [installer](https://github.com/NousResearch/hermes-agent/blob/a9a54245b2311c705d29050b7f9868c015917aec/tools/skills_hub_install.py), MIT with the full notice retained. Immutable blob reads use the [GitHub tree](https://docs.github.com/en/rest/git/trees) and [blob](https://docs.github.com/en/rest/git/blobs) contracts. Branch's in-memory quarantine and existing package conversion replace upstream filesystem quarantine.

Runtime network, archive and UI acceptance is unverified. Private repositories, nested references, script execution and automatic update checks are unsupported. Integrate the separate resource and scanner improvements when combining this with those changes; this PR retains the existing package/activation behavior and adds a complete pre-install scan of kept reference text. Omitted path display is bounded to sixty-four entries. Discard the preview to cancel; an expired or failed one-use approval requires a new inspection.
