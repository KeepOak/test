# Local passage reranking

When model reranking is not selected, Branch uses the independently selected local embedding source to compare the question with the candidate passages. It orders them by cosine similarity and removes passages below the relevance floor. If the source is off, remote, unavailable, changed while reading, or returns invalid vectors, word counts provide the existing fallback. Model reranking keeps its existing behavior.

`GET /api/retrieval` returns the reranking settings. `POST /api/retrieval` accepts `relevanceThreshold` between -1 and 1, default 0.1. This floor applies only to cosine scores; word-count and model scores have different meanings. The default is a starting point, not a calibrated relevance guarantee for every embedding model. A valid local result below the floor stays empty rather than bringing discarded passages back through word fallback. Results identify the actual second pass as `embeddings`, `words`, or `model`; local reranking reports zero model rerank calls.

The local pass uses one query of at most 500 characters and the first 2,048 characters of at most fifty passages in one batch from one reader. It validates finite, nonzero, equal-sized vectors of at most 8,192 dimensions and uses stable input order for ties. The returned passages retain their full original text. Preparation and embedding share a ten-second abortable signal. No cross-query vector cache or remote embedding fallback is added.

The actual factory uses the shared source's current connection settings, honors its existing transport, and checks fresh owner/profile, App lock, Lockdown, full app key, network rules and source configuration before and after awaited work. Locking the app aborts pending local reranks. A selected remote source is never contacted for this pass. It does not change the upstream retrievers' own embedding behavior.

The approach was reviewed in [Open WebUI's pinned reranking and relevance filter](https://github.com/open-webui/open-webui/blob/8bd8b4fac5e059578ac0c74b3c18d11139f88b7d/backend/open_webui/retrieval/utils.py#L1808-L1850). Its pinned license includes branding conditions; no Open WebUI implementation was copied. Branch uses original code and its existing cosine function. No retrieval, database, model, embedding service, app or test was run. Runtime quality, latency and threshold calibration remain unverified. Rollback removes the local factory hook and returns non-model reranking to word counts.
