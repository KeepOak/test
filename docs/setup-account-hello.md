# Setup account greeting

UP-UI-059 adds an automatic bounded hello when the owner enables an account in setup's Models step or completes the existing successful sign-in path while that step is open. A saved form does not trigger a connected receipt. Sign-in success events carry the exact primary, additional or merged account id. The greeting uses that account's provider directly; it cannot fall through to another pool account and mislabel the result. Single-account connections such as Gemini use the existing preset-specific bounded test path. The returned greeting carries the configured preset/model and exact account identity only after an actual completion; it does not claim a provider-reported model id when the completion contract has none.

The UI shows the reply, model, preset and account with Change. Existing Choose the model later behavior remains. Superseded setup greetings cannot replace newer results. The new hello API checks owner/profile/signed-person/short-key/lock/lockdown before and after provider setup and completion, limits the request to 16 tokens with a 30-second signal, and respects account disablement and saved spending caps.

ChatGPT device sign-in polling stops at its returned expiresAt; Gemini stops at expiresInMs. Late poll callbacks cannot reconnect a closed or replaced flow. Program sign-ins retain their existing engine-owned bounded process lifetime; no fictional provider expiry is added. Known no-model submit failures preserve the draft and open Add account or setup Models. Other transient or provider authentication failures retain existing error handling; no heuristic classifies all errors as missing accounts.

Reviewed existing PRs #1016 (account call usage receipts), #1142 (personal Google/Microsoft/Spotify identity), and #974 (one setup journey). They do not supply this setup greeting flow. This narrow frozen-base change has no stack prerequisite and does not claim their unmerged behavior. The greeting result is immediate evidence from a future live completion, not a persisted #1016 call receipt.
