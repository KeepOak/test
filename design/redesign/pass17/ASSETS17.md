# Pass 17e art

Every file this pass added, what made it, and its size. All of it lives under `assets/art17/` (nothing older was touched) and is listed for code in `assets/art17/manifest17.json`.

**Models (on higgsfield.ai, the owner's account):** stills with **Nano Banana Pro** (2K; 16:9 for scenes, 4:5 for everything on magenta). Loops with **Kling 3.0** (the site shows no separate "pro" mode for it, so the highest setting was used: 1080p), 5 s, sound off, prompt enhancer off, 1:1, with the **same square still as both start and end frame** so each loop closes on itself. Prompts name no studio, brand or existing character.

**Pipeline (`key17.py`, new; `keyvid.py`/`rekey.py` untouched):** each magenta still is padded to a square in its own sampled backdrop colour and uploaded as the start and end frame. The key colour is sampled from the frame edges (the model's "magenta" drifts to mauve or lilac) and never fixed. Thresholds scale with how saturated that colour is. The subject's inside is made solid unless it's glass (Nib and the feature pictures use `--glass`). Magenta spill is pulled from the edges and stray haze is dropped, then the result is cropped to the subject and written as VP9 `yuva420p` WebM. Every loop was checked frame by frame over a dark and a light checkerboard for fringe, see-through bodies and seams. Seam difference (first to last frame) is at or under a normal frame step for every loop.

**Downloads:** the finished files were fetched straight from the site's own result CDN, the URL each result shows on the page, and not with the page's download button. It's the same file either way. It's recorded here because the brief asked for page downloads.

**Total:** 45 assets plus the manifest, 4.7 MB (the older assets folder is about 20 MB).
